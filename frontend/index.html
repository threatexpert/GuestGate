关于 GuestGate

GuestGate 是一款开源的 VMware 虚拟机透明代理网关。你可以在 Windows 宿主机上为每台虚拟机指定上游代理，无需在客户机里逐个配置应用。

架构级防漏原理（零直出保障）

  1. 先切断外网： 将虚拟机网卡设为仅主机模式（Host-Only）或隔离模式，从底层剥夺其直连公网的能力。
  2. 单点搭桥： GuestGate 直接监听该虚拟机网卡的底层数据包，并实现将其透明代理转发至上游代理。

可靠性闭环： GuestGate 是虚拟机通往外部的唯一桥梁。无论代理服务停止、程序意外退出还是上游节点故障，桥梁断开即刻彻底断网。

两种模式的说明

网络行为严格隔离模式仅主机模式
虚拟机互访无法直接互访。同一仅主机网段内可直接互访。
宿主机端口无法访问。可访问宿主机对该网段开放且防火墙放行的端口。

两种模式都通过指定的上游代理访问外网。停止代理后，网卡仍留在所选网络，本地互访范围见上表。

如何为每个 Clash 节点分配独立本地端口

  1. 在宿主机运行 FlClash 或 Clash Verge Rev，并启用含有节点的订阅。
  2. FlClash：右键目标配置，打开「扩展」并选择「脚本」。在「前往配置脚本」中新建脚本、粘贴并保存，返回选中它，点「立即应用」。
    Clash Verge Rev：右键目标订阅，打开「扩展脚本」（部分版本叫「编辑脚本」），粘贴并保存。启用该订阅并切到规则模式。
  3. 在客户端的「端口对照」代理组查看节点对应的端口。例如，虚拟机 A 的上游代理填 127.0.0.1:18901，虚拟机 B 填 127.0.0.1:18902。分别启用代理并核对出口 IP。

脚本会把这份配置的分流规则替换为全部走「主出口」。端口按节点顺序分配，订阅更新后请重新核对。
